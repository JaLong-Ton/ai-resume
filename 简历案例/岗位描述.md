## 一、医生（临床执业医师）

1. 负责门诊、住院患者的问诊、查体、诊断，制定诊疗方案、开具处方及检查单；
2. 执行医嘱、书写病历、病程记录、出院小结等医疗文书，保证文书规范完整；
3. 参与病房查房、疑难病例会诊，跟进患者病情变化，及时调整治疗方案；
4. 开展常见病、多发病治疗，处理急诊突发情况、术后患者康复跟进；
5. 做好患者健康宣教、用药指导、复诊提醒，遵守医疗规范及医德医风；
6. 配合医院质控、院感防控、继续教育及科室日常医疗工作。

## 二、会计助理

1. 协助主办会计整理审核原始凭证（发票、收据、报销单等），整理装订会计档案；
2. 负责日常费用报销登记、流水台账记录，核对收支明细；
3. 协助录入记账凭证、核对往来账款，整理应收应付对账资料；
4. 辅助完成月度、季度票据整理、税务资料准备，配合纳税申报；
5. 负责开票、登记发票台账，整理工资表、社保公积金相关辅助资料；
6. 完成财务资料归档、报表基础整理及领导安排的其他财务辅助工作。

## 三、医护护士（临床护士）

1. 严格执行医嘱，负责患者给药、输液、打针、换药、生命体征测量等基础护理；
2. 做好病房晨间护理、基础护理、专科护理，观察患者病情、意识及情绪变化；
3. 准确书写护理记录、体温单、医嘱执行记录等护理文书；
4. 负责病房环境卫生、消毒隔离、医疗垃圾分类处理，落实院感防控；
5. 对患者及家属进行健康宣教、康复指导、饮食及作息注意事项告知；
6. 配合医生抢救急诊、危重病人，协助手术前后护理及科室轮值夜班。

## 四、金融分析师

1. 宏观经济、行业政策、市场行情研究，收集整理行业及公司财务数据；
2. 对上市公司、投融资项目进行基本面分析、财务建模、估值测算；
3. 撰写行业研究报告、个股分析报告、投资策略报告，输出投资观点；
4. 跟踪市场动态、政策变化，研判资产价格走势，提供投资参考建议；
5. 参与项目尽调、数据整理、模型搭建，辅助投资决策与资产配置；
6. 整理金融数据库，维护研究台账，对内对外提供专业金融分析支持。

## 五、Java 开发工程师

1. 负责后端业务系统、接口服务的设计、开发、编码及单元测试；
2. 参与需求评审、架构设计、数据库表结构设计，编写技术设计文档；
3. 使用 Java、SpringBoot、SpringCloud 等主流框架开发微服务、后台管理系统；
4. 对接前端、测试及产品同事，联调接口、修复线上 Bug、优化系统性能；
5. 参与代码评审、版本迭代、线上部署、日常运维问题排查；
6. 优化业务逻辑、数据库 SQL 语句，提升系统稳定性、并发能力和可扩展性。
